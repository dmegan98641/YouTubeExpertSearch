# Chrome Extension Module - YouTubeExpertSearch

Ez a mappa fogja tartalmazni a **YouTubeExpertSearch** Chrome bővítmény (Manifest V3) kódját.

## Tervezett funkciók
- Chrome Toolbar / Side Panel integráció
- YouTube weboldali tartalom elemzés és gyorskereső overlay
- Szinkronizáció a backend szolgáltatással és a teszt UI-val
