# Backend Module - YouTubeExpertSearch

Ez a mappa fogja tartalmazni a **YouTubeExpertSearch** backend szolgáltatásait (Node.js / Express / Fastify / Python API).

## Tervezett funkciók
- YouTube Data API & Transcript proxy kérések
- AI összefoglalók és feldolgozó szolgáltatások
- Felhasználói beállítások és mentett adatok tárolása
